# ==================== replacement_rules.txt 使用说明 ====================
# 作用：注音完成后，对整份结果做“字符串替换”：找到原文就换成替换文，所有出现的地方都换。
# 这是流程的最后一步，看到的是带内部标记的文本，不是普通字幕，所以写法比 context_rules.txt 更底层。
# 只改日语读音时，优先使用 context_rules.txt（带前后文，不用懂内部标记）。
# 本文件适合 context_rules.txt 做不到的事。程序内置的默认规则（把 <ruby> 转成 {\k1} 等）不在本文件里，不要重复添加。
#
# 【格式】每行一条：  原文<TAB>替换文
#   - 中间必须是一个真正的 Tab 键（文中的 <TAB> 表示按一下 Tab 键）
#   - 没有 Tab 的行会被当作注释忽略（包括这些说明）。说明行里不要出现 Tab，否则会被当成规则
#   - 替换文不能为空，所以不能用来删除文字
#   - 规则从上到下依次执行，后面的规则看到的是前面规则替换后的结果
#   - 对日语、英语、中文三种注音模式都生效
#   - &#124; 会被还原成竖线 |
#   - 在程序的“自定义注音”窗口点保存，会按窗口里的规则重写本文件，这些说明行会丢失，请先备份
#
# 【注音文本的内部格式】替换发生时，文本长这样：
#     {\k1}部屋|<へや{\k1}に{\k1}入|<い{\k1}れない
#   即：{\k1} + 汉字 + |< + 读音 + {\k1} + 送假名
#   - 汉字与读音之间是 |<，每个注音块前后都有 {\k1}
#   - 没有汉字的部分（に、れない）原样保留
#   - {\k1} 是“反斜杠 k 1”，原文和替换文都要原样写出
#
# 【示例】（以下都是注释，已核对过替换结果）
#   1. 带上下文的读音修正（范围小，推荐）：把前面的 に 和后面的送假名都写进去
#        {\k1}に{\k1}入|<い{\k1}れない<TAB>{\k1}に{\k1}入|<はい{\k1}れない
#      只有“に + 入れない”这个组合会被改，水を入れない 不受影响。
#   2. 规则按顺序叠加：
#        見|<けん{\k1}て<TAB>見|<み{\k1}て
#        見|<み<TAB>見|<けん
#      两条连着执行，第一条的结果被第二条改回去，最终是 けん。后写的规则能推翻先写的。
#
# 【危险写法】（都是全局替换，所有出现的地方都会变）
#   - 原文太短：  生|<う<TAB>生|<なま
#       本意只想改某个词，结果 生まれる 的读音也变成 なま{\k1}まれる。
#   - 不含标记的普通文字：  は<TAB>わ
#       会把正文里每一个“は”都换成“わ”（私は → 私わ），连显示出来的字幕文字都被改了。
#   - 改坏结构：替换文里少写一个 {\k1}，或把 |< 写错，注音就可能和文字错位。
#     只想改读音时，替换文里除读音外的部分必须和原文完全一致。
#   - 替换文包含原文（如 A 换成 AB）：每条规则只扫描一遍，不会死循环，但后面的规则可能再次命中它。
# ======================================================================
見|<けん{\k1}て	見|<み{\k1}て
