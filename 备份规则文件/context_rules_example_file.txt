# ==================== context_rules.txt 使用说明 ====================
# 作用：日语注音时，按“前后文”指定某个词的读音。前后文都对得上才生效，不会误伤别处。
# 与 replacement_rules.txt 的区别：本文件决定“选哪个读音”（在注音阶段），
# replacement_rules.txt 是注音完成后对结果文本做字符串替换（最后一步）。
# 改读音优先用本文件：不用懂内部标记，也更不容易误伤。
#
# 【格式】每行一条：  前文[目标词]后文<TAB>平假名读音
#   - [ ] 里是要改读音的词；前文、后文只用来限定场景，本身不会被改动，可以留空
#   - 规则与读音之间必须是一个真正的 Tab 键，用空格无效（文中的 <TAB> 表示按一下 Tab 键）
#   - 读音只能是平假名（可含长音 ー），要写整个目标词的读音，包括送假名：
#     入れ 写 はいれ（不是 はい）；辛い 写 からい（不是 から）
#   - 以 # 开头的行是注释，空行忽略。不能把注释写在规则行的末尾
#   - 文件用 UTF-8 保存，放在程序（exe）同一目录或其 dict 子目录
#   - 修改后需要重启程序才生效；只在“日语注音”模式下生效；只匹配同一行字幕，不跨行
#
# 【关键：目标词必须是完整的分词】
#   目标词的开头和结尾必须正好落在 Sudachi 的分词边界上。
#   查看分词：勾选主界面的“导出日文分词”，处理后输出目录会多一个 xxx_tokens.txt。
#   例如 部屋に入れない 被切成：部屋 | に | 入れ | ない
#     可以：に[入れ]ない        （入れ 是完整的一个词）
#     可以：[入れない]          （入れ + ない，两个完整的词）
#     无效：に[入]れない        （把“入れ”从中间切断了，不报错，只是不生效）
#   前文、后文不受这个限制，可以从词的中间开始，如 屋に[入れ]ない。
#
# 【多条规则同时命中】前文+后文更长的优先；一样长时，写在前面的优先。
#
# 【示例与极端情况】（以下都是注释，已实测过效果）
#   1. 基本写法：
#        に[入れ]ない<TAB>はいれ       部屋に入れない → 入(はい)れない
#      只改匹配到的那一处：同一句“部屋に入れない、水を入れない”里，只有前一个 入れない 被改，
#      水を入れない 仍读 いれ。
#   2. 只写后文（何 后面是 で 时读 なん，其余不管）：
#        [何]で<TAB>なん               何で行く → なん；何も知らない 不受影响
#   3. 形容词连同送假名一起写：
#        カレーは[辛い]<TAB>からい     カレーは辛い → から；心が辛い 仍读 つら
#   4. 名词按前文区分：
#        リンゴの[実]<TAB>み           リンゴの実 → み；実は元気 仍读 じつ
#   5. 整句锁定（目标跨多个词也行，读音写整段）：
#        [部屋に入れない]<TAB>へやにはいれない
#   6. 长短规则搭配（长的优先，短的兜底）：
#        に[入れ]ない<TAB>はいれ
#        [入れ]ない<TAB>いれ           部屋に入れない → はいれ；水を入れない → いれ
#
# 【危险写法：没有前后文 = 全局生效】
#   [何]<TAB>なに     这样会让所有单独的“何”都读 なに，连 何の音（应为 なん）也被改错。
#   务必加上前文或后文，把范围限定到你确实要改的场景。
#
# 【以下写法都不会报错，但整行会被忽略或永远匹配不上】
#   - 用空格代替 Tab：                      に[入れ]ない  はいれ
#   - 读音写成片假名、汉字，或带说明文字：  に[入れ]ない<TAB>ハイレ / はいれ # 进不去
#   - 一行里写了多对 [ ]：只认第一对，后面的 [ ] 被当作普通文字，规则永远对不上
#   - 目标词把分词切断（见上文“无效”示例）
#   - 读音和汉字对不上，如 に[入れ]ない<TAB>はい（缺了送假名 れ）
# =====================================================================

に[入れ]ない	はいれ
[何]も	なに
